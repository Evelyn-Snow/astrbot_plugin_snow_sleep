# 机器人作息

让机器人在设定时间（默认 00:00-07:00）进入休息：

- 休息期间所有消息（含 @、名字、戳一戳、图片）不会被回复或处理
- LivingMemory 的全群被动捕获同步暂停（"不用全读消息"），苏醒后恢复
- `/` 命令仍然可用；网页测试台默认豁免（方便夜间调试）
- 支持跨午夜窗口（如 23:30-07:30）

实现：最高优先级事件守卫直接拦截 + 每 60 秒同步 LivingMemory 捕获开关。

## 临睡晚安道别（v0.2.0）

休息开始前几分钟内（默认 5 分钟）仍在私聊她的对象，会在她休息前收到一句晚安道别：

- 仅私聊；群聊、@、命令都不触发
- 「正在聊天」= 对方最近 N 分钟（默认 5）发过私聊消息
- 晚安语由模型按人设现写，失败时退回固定文案；每位对象每晚最多一次
- 配置：`goodnight_enabled` / `goodnight_window_minutes` / `goodnight_active_minutes`
